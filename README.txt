RANDO RADAR — V1.3
==================

Fonctions principales :
- Carte topographique OpenTopoMap + carte OpenStreetMap
- Carte plein écran au toucher + bouton Fermer
- GPS en direct sans recentrage forcé ; bouton ◎ pour revenir à sa position
- Import / export GPX
- Création d’itinéraire à pied ou à vélo avec routage OpenStreetMap/FOSSGIS OSRM
- Enregistrement local des parcours créés
- Altitudes de parcours via Open-Meteo / Copernicus DEM
- Suivi d’activité randonnée ou vélo : trace GPS en direct, distance, durée, vitesse, moyenne
- Pause / reprise / fin d’activité et export de la trace en GPX
- Destination choisie sur la carte pendant une activité : distance, cap, direction relative, ETA
- Radar pluie RainViewer animé sur les 2 dernières heures
- Météo locale Open-Meteo / modèles Météo-France
- Analyse météo en 6 points le long d’un GPX selon mode Rando ou Vélo
- Installation PWA sur Android

Important :
- Le guidage vers une destination dans cette version est un guidage GPS direct (cap + distance + ETA).
  Le guidage virage-par-virage sur sentiers peut être ajouté ensuite.
- La carte reste libre même pendant le suivi : elle ne se recentre que sur pression de ◎.
- La géolocalisation et le Service Worker nécessitent HTTPS (ou localhost).
- Les services publics de routage sont utilisés avec parcimonie et peuvent être indisponibles.
